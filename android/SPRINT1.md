# Sprint 1 - two phones, no internet

Goal: two Android phones talk to each other with mobile data OFF.

## Setup (both phones)
1. Install the app from Android Studio (Run, one phone at a time).
2. Turn ON: Bluetooth, Wi-Fi, Location. Mobile data can be off.
3. Open Rylaide. Use the SAME group code on both. Tap Start and allow every permission.
4. Wait for "Connected to rider ..." on both screens (usually 5-30 seconds).
5. Tap the big mic button on one phone and speak. The other phone should play it.

## Testing tips
- Use earphones or a headset, or put the phones in different rooms. Two open
  speakers next to each other make a loud squeal (feedback).
- Watch "Frames sent / received". Sent should climb while you speak, received
  should climb on the other phone.
- If you hear nothing but frames arrive, raise the phone volume.
- Tune the slider so your voice passes and idle noise does not.

## What to report back
- Seconds until the phones connected
- Whether voice was clear, choppy or delayed (rough guess in seconds)
- Distance at which it dropped
- Which phones (brand, model, Android version)
